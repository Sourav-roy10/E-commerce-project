# 📊 E-Commerce Business Dashboard

An interactive  Power BI dashboard analyzing 5,000 e-commerce orders — covering revenue , regional/payment performance,and customer satisfaction.

## 🛠 Tools Used
- **Python (Pandas)** – data cleaning, validation, and date correction
- **Excel** – manual review and file preparation
- **Power BI** – data modeling, DAX, dashboard design

## 📁 Dataset
5,000 orders with fields: order date, category, region, quantity, price, discount, payment method, delivery days, rating, and revenue.



## 🔑 Key Insights
- Electronics drives the highest revenue despite being 1 of 4 categories
- Revenue is evenly spread across all regions — no single region dominates




## 🙋 About
Portfolio project demonstrating end-to-end analytics: data cleaning (Pandas), validation (Excel), and interactive dashboard design (Power BI).
